## 🎯 Overview & What This App Does
Divine — AI Assistant for Keldia at Sixth Sense Studio (Procurement, Houzz Pro Tracker & Budgets, Vendor-Payment Prep, Payroll Prep, Logs & Reporting)

Built with **Node.js, JavaScript, Next.js, React, Tailwind CSS, TypeScript, HTML, Node.js / JS, lucide-react, next, react, react-dom, clsx, tailwind-merge, @types/node, @types/react, @types/react-dom, autoprefixer, postcss, tailwindcss, typescript**, this application integrates into Geppy's App Universe and is managed via GitBridge.

## 🚀 Key Features & Workflows
- **Core User Flow**: Specialized workflows with live state and local responsiveness.
- **GitBridge Integration**: Live Designer mode, proactive AI suggestions, one-click Git commit & GitHub push.
- **Central API Key Vault**: Centralized Gemini AI integration via `.env` configuration.

## 🛠️ How to Run & Develop Locally
1. **Navigate to App Directory**:
   ```bash
   cd "d:\Geppy_Apps\Devine2"
   ```
2. **Launch Application**:
   ```bash
   npm run dev
   ```
3. **Open in Browser**:
   Visit `http://localhost:3001` in your browser.
