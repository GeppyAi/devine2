# Design Document: Divine — AI Operations & Procurement Assistant (Sixth Sense Studio)

> [!IMPORTANT]
> **Core Architectural Invariant (Strict Air-Gap & Human-in-the-Loop):**
> Divine is a **preparation, comparison, tracking, and drafting engine only**. It has **zero outbound write integrations** to email servers (no SMTP/send scopes), Houzz Pro, QuickBooks Payroll Online, banking/Zelle, or vendor portals. Every output is explicitly watermarked with a verification status (`Draft`, `Needs Human Verification`, `Discrepancy Found`, `Waiting for Meliza’s Written Approval`) and requires explicit human review and manual action outside the system.

---

## 1. Executive Summary & System Purpose

**Divine** is an internal Web Dashboard + AI Chat Workspace built for **Sixth Sense Studio**. Divine assists your operations team across five core operational pillars:
1. **Procurement Support** (Quote comparisons, draft POs, 3-way matching between Quotes/POs/Acknowledgments/Invoices, open order tracking, receiving/Mafer coordination, and draft vendor follow-ups).
2. **Houzz Pro Project Tracker & Budget Support** (Proposed tracker updates from source docs, budget vs. actual procurement cost comparisons, risk flagging, and draft client/project status updates).
3. **Vendor-Payment Preparation** (Payment approval packets, document completeness checks for W-9/COI/Lien Releases, vendor payment detail checks, draft payment logs, and Meliza approval request packets).
4. **Payroll Preparation** (Single W-2 employee hours summarization, anomaly/gap detection, deadline reminders, and Meliza approval summary generation prior to manual entry into QuickBooks Payroll Online).
5. **Logs, Reminders, & Reporting** (Daily EOD summaries, follow-up reminders, weekly budget/lead-time/payment reports, and monthly vendor performance scorecards).

## 2. Firm Limits & Safety Architecture ("Air-Gap by Design")

### 2.1 Prohibited Capabilities (Hard-Blocked in Code)
* **No Outbound Messaging:** No `mailto:` auto-triggers, no SendGrid/SMTP/Gmail Send APIs, no Slack/SMS bots that message external vendors or clients. All drafted messages render in a **"Draft Box"** with a `"Copy Draft after Review"` button.
* **No Financial Execution:** No Plaid/Zelle/banking APIs, no QuickBooks write APIs, no payment links.
* **No Autonomous State Promotion:** Divine can **never** set a record's status to `Verified`, `Approved`, `Submitted`, or `Paid`. Only an authenticated human action by the Reviewer (uploading or logging proof of completion, such as Meliza's written approval or a Zelle confirmation reference) can transition an item to a completed state.
* **Out-of-Scope Accounting Guardrail:** If prompted to perform bookkeeping, general ledger review, bank reconciliations, month-end close, tax calculations/filings, or client collections/invoicing, Divine politely declines and cites its operational scope boundary.

### 2.2 Mandatory Status Badges
Every artifact, table row, packet, and draft generated by Divine must carry one of these explicit system badges:

| Status Badge | Set By | Meaning |
| :--- | :--- | :--- |
| `DRAFT` | Divine | Newly generated PO, message, tracker row, or log entry. Unverified. |
| `NEEDS_VERIFICATION` | Divine | Extracted or compared data awaiting human check against source documents. |
| `DISCREPANCY_FOUND` | Divine | Mismatch detected (SKU, finish, qty, price, dates, fees, hours, or missing doc). |
| `VERIFIED_BY_REVIEWER` | Reviewer (Manual UI Action) | Reviewer has checked the draft against original source documents. |
| `WAITING_MELIZA_APPROVAL` | Reviewer (Manual UI Action) | Packet verified by Reviewer; awaiting Meliza's written sign-off. |
| `MELIZA_APPROVED` | Reviewer (Manual Log + Ref) | Reviewer records that Meliza provided written approval (with date/reference note). |
| `COMPLETED_MANUALLY` | Reviewer (Manual Log + Ref) | Reviewer records that they sent the PO, posted to Houzz, sent Zelle, or submitted QB Payroll. |

## 3. Indexed Houzz Pro Software Knowledge Base (Built-In AI Context)

Divine operates alongside **Houzz Pro** and has direct, structured knowledge of the 6 official Houzz Pro workflows (stored in `src/data/houzzKnowledge.ts`):

1. **Product Library (`My Items`) & Draft Project Items** (`https://pro.houzz.com/pro-help/r/how-to-use-the-product-library-in-houzz-pro`)
   - Navigation: `Left Nav → Company Icon → Library → My Items`.
   - Supports Houzz Pro Clipper, Manual Entry (up to 5 images), CSV Bulk Import (up to 500 items), and assigning sourced products as **Draft Project Items** before formal proposals.
2. **Maximizing the Selections Tracker as a Designer** (`https://pro.houzz.com/pro-help/r/how-to-maximize-the-selections-tracker-as-a-designer`)
   - Navigation: `Project Overview → Planning → Selections → Tracker Tab`.
   - Enforces upfront data hygiene (Room, Category, Linked Vendor), pairs with **Selection Boards** for visual client approvals, and utilizes **Two-Way Document Sync** between inline Tracker order-status updates and linked Purchase Orders/Invoices.
3. **Using the Selections Tracker (Views & Columns)** (`https://pro.houzz.com/pro-help/r/how-to-use-the-selections-tracker`)
   - Switches between Preset Views (`Planning`, `Financials`, `Procurement`), customizes columns via the 3-bar Columns icon, and tracks inline fields (`Procurement Status`, `Order Date`, `Estimated Delivery`, `Purchase Order`).
4. **Creating Purchase Orders in Houzz Pro** (`https://pro.houzz.com/pro-help/r/how-to-create-purchase-orders`)
   - Converts line items from Estimates, Proposals, or Invoices (`Actions → Create Purchase Order`) or approved Selection Boards (`Convert` button) and assigns/confirms vendors.
5. **Merging Purchase Orders in Houzz Pro** (`https://pro.houzz.com/pro-help/r/how-to-merge-purchase-orders`)
   - Consolidates multiple **Draft** Purchase Orders belonging to the **same Vendor and same Project** via `Open Draft PO → Actions → Merge Purchase Orders`. Divine automatically detects and flags eligible Draft POs for you to merge.
6. **Managing Vendors in Houzz Pro** (`https://pro.houzz.com/pro-help/r/how-to-manage-your-vendors`)
   - Navigation: `Left Nav → Company Icon → Vendors`.
   - Supports CSV Vendor List Import (`Actions → Import Vendor List`) and custom category/trade tags (`Actions → Manage Tags`).
